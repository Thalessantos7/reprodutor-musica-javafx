# 🎵 Reprodutor de Música
O projeto consiste no desenvolvimento de um sistema reprodutor de músicas em Java utilizando JavaFX. O sistema permitirá a reprodução de arquivos de áudio, oferecendo funcionalidades como reproduzir, pausar, parar, avançar, retroceder e controlar o volume das músicas. Além disso, o usuário poderá adicionar e remover músicas da biblioteca por meio de uma interface gráfica simples e intuitiva.

---

## 🎯 Objetivo do Sistema
O sistema tem como objetivo facilitar a reprodução e a organização das músicas cadastradas na biblioteca por meio de uma interface gráfica simples e intuitiva.

---

## 👤 Público-alvo
O sistema será destinado a usuários que possuem interesse em música e desejam reproduzir e organizar suas músicas de forma simples e prática.

---

## ⚙️ Funcionalidades do Sistema
- Reprodução de arquivos de áudio;
- Pausa e parada de músicas;
- Avanço e retrocesso da reprodução;
- Controle de volume;
- Adição e remoção de músicas da biblioteca;
- Exibição das informações das músicas.

---

## 🛠 Tecnologias Utilizadas
- Java
- JavaFX
- Programação Orientada a Objetos (POO)
